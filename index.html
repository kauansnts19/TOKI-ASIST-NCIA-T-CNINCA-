Programação Orientada a Objetos (POO)

A POO é um paradigma de programação que organiza o código em "objetos", facilitando a manutenção, reutilização e escalabilidade.

1. Classes

São como "plantas" ou modelos que definem as propriedades e comportamentos dos objetos.

class Carro {
    constructor(modelo, cor) {
        this.modelo = modelo;
        this.cor = cor;
    }
}

2. Objetos

Instâncias concretas criadas a partir de uma classe.

const meuCarro = new Carro("Tesla Model 3", "Azul");

3. Encapsulamento

Protege os dados internos da classe, expondo apenas o necessário.

Usa private, getters e setters.

4. Herança

Permite que uma classe herde propriedades e métodos de outra.

class CarroEletrico extends Carro {
    constructor(modelo, cor, bateria) {
        super(modelo, cor);
        this.bateria = bateria;
    }
}

5. Polimorfismo

Permite que objetos de diferentes classes sejam tratados de forma uniforme.

Um mesmo método pode ter comportamentos diferentes dependendo da classe.
